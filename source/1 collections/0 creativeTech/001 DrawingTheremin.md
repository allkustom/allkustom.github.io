# Project Description

This work is inspired by a theramin, an instrument that plays without touching it. The location of the hand is sensed by an ultrasonic sensor, and the canvas moves based on that coordination. Furthermore, I am exploring the possibility **that the physically disabled can use this tool.**
</div>

Users can control the pen position with **their left and right hands**. The pen follows the direction of the hands, and its speed adjusts based on the distance moved. A button held in the left hand allows the user to lift the pen.
